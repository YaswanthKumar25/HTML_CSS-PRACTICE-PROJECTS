# Frontend Practice Portfolio

A personal collection of mini frontend projects built while practicing **HTML, CSS, and JavaScript**.

## About This Repository

This repo contains small, focused projects to improve:

- Responsive layouts
- UI styling and component design
- DOM manipulation
- Basic app logic (counter, to-do, validation)

## Project Gallery

| Project Folder | Type | Main File | Notes |

| `3d Style` | UI Experiment | `3d Style/index.html` | 3D visual styling practice |

## Tech Stack

- HTML5
- CSS3

## Quick Start

```bash
git clone <your-repo-url>
cd <your-project-folder>
```

Open any project file directly in your browser, for example:

- `TodoList/index.html`
- `Responsive Navbar/index.html`
- `Rsto/index.html`
